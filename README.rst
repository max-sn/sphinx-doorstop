``sphinx-doorstop``
===================

|pypi python versions| |pypi package version| |documentation status|

A Sphinx extension allowing to include Doorstop_ documents and items in your
Sphinx_ build. It should support any existing Doorstop project and behave as if
``doorstop publish`` had a Sphinx builder out of the box.

.. _Doorstop: https://doorstop.readthedocs.io/
.. _Sphinx: https://www.sphinx-doc.org/
